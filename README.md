# cloud-course-notes 课程学习笔记

## 第一章 版本控制与 Git 基础学习记录

### 一、本章学习认识

本章主要学习了文件本地保存与版本控制的区别，理解了 Git 版本管理的核心作用。普通的本地文件保存仅能覆盖更新文件，无法记录修改过程、无法回溯历史版本；而通过 Git 的 Commit 提交功能，可以将一组修改打包为独立版本，记录每一次的变更内容，方便后期查看、追溯与还原文件状态。

同时掌握了入门阶段的简易文件获取方式（ZIP 下载），了解完整 Git 工作流为后续拓展学习内容，明确了版本提交备注的书写规范：清晰说明**改了什么**，保证版本记录可追溯、可查阅。

### 二、示例来源

本学习文档为课程配套实操练习内容，基于代码平台私有仓库搭建实验完成，所有操作均按照课程第一章版本控制实验要求执行。

### 三、本次完成的修改

1. 成功创建私有仓库 `cloud-course-notes`，仓库权限设置为 Private，自动初始化 README 文件。
2. 在线编辑仓库 README.md 文档，补充第一章版本控制相关学习内容。
3. 完成版本提交操作，提交说明：**补充第一章学习记录**。
4. 核对仓库提交记录，确认本次修改成功保存，完成基础的版本提交实操练习。

---

学习小结：通过本次实验，区分了本地保存与 Git 版本提交的本质区别，掌握私有仓库创建、文档编辑、在线 Commit 提交的完整基础流程，初步掌握版本控制的核心使用逻辑。
